# Рейтинг мемов по реальным реакциям — срез 24.11.2026

- Источник: Apify — `clockworks/tiktok-scraper` (поиск, 30 роликов × 15 мемов), `data-slayer/instagram-search-reels` (8 запросов).
- Фильтр: ролики с 01.01.2025.
- Индекс 0–100 = 40% лог-медиана просмотров + 30% медианная доля репостов + 30% доля роликов за 90 дней (нормировка на максимум).
- Затраты ≈ $2 из бюджета $5.
- `meme_metrics_2026-11-24.csv` — агрегаты по мемам (без ников и ссылок на авторов). `analyze.py` — расчёт.

## Срез 26.11.2026 — мемы × темы вопросов
- Дополнительно 500 роликов TikTok: 10 тем вопросов × 50 («интроверт мем», «тревожность мем» и т.д.), ≈ $1,8.
- Метрика: (репосты + сохранения) / просмотры. Бутстрэп-ДИ медиан, Kruskal–Wallis, Mann–Whitney с поправкой Холма.
- `stats_2026-11-26.json` — результаты, `stats2.py` — расчёт, `stats2_output.txt` — вывод. Сырые ролики с никами авторов не публикуются.
